# 思源原文剪贴：实现与验收

日期：2026-09-21。

## 已实现

- 桌面文章菜单新增「剪贴原文到思源」；「设置 → 集成 → 思源网页剪贴」可手动输入网址，不需要 RSS 订阅。
- 输入原网页 URL，先抓取源站 HTML；无法提取时打开独立 Electron 网页窗口，读取脚本执行后的 DOM。登录或验证需在这个窗口完成，然后重新提取。
- 预览完整提取结果、来源、提取方式及图片数量，可修改标题；保存前必须配置目标笔记本及上级文档路径。
- 通用网页使用 Readability，微信公众号使用既有 `web-clipper-core` 适配器；HTML 转 Markdown、表格规范化和来源地址规范化复用同一核心。
- 图片逐一下载并上传到思源，读取真实资源并比较 SHA-256；全部成功后将 Markdown 图片引用替换成思源 `assets/...` 路径。
- 文档创建后回读全文、路径、来源、任务标记和图片资源。思源会改写 Markdown 表格分隔线，因此正文比对忽略空白和标点格式差异。
- 本地 SQLite 持久保存任务与图片进度；重复保存默认复用已完成文档，不覆盖后续人工修改；可明确「另存新副本」。失败任务可以重试。
- 任务历史使用单独的轻量回执和时间索引，刷新进度无需反复读取、解析整篇网页快照；保存任务也不保留无用的原始 HTML。
- 创建文档后断线时标记为「待确认」，重试先寻找原目标并验证任务标记，不盲目再次创建，也不会关联同名的其他笔记。
- Token 使用 Electron 系统加密存储，不返回给渲染层，不随通用集成配置导出。切换 API 地址不会自动沿用旧 Token。
- 桌面「阅读全文」使用相同的原网页抓取链路，不再将本地 RSS 内容当作成功提取的全文。
- 英文、简体中文、日文界面及 CI 检查均已补齐。

## 使用步骤

1. 打开思源，在 FoLocal「设置 → 集成」填写思源 API 地址和令牌。
2. 点击「连接并读取笔记本」，选择笔记本及上级路径，再点击「保存目标位置」。
3. 从文章菜单进入，或在设置中直接粘贴原网页地址，点击「提取原文」。
4. 如果需要登录，完成源网页窗口中的登录，然后重新提取；返回 FoLocal 检查正文预览。
5. 点击「剪贴原文到思源」。只有文档与图片核验成功才显示完成；可从剪贴记录打开对应笔记或重试失败任务。

## 当前边界

- 独立源网页窗口不共享用户常用浏览器的登录状态，首次访问受限内容可能需要登录。无法取得的网站内容不会由 RSS 或 AI 补齐。
- 提取器无法证明所有网站都已完整加载，也不能突破网站实际返回的权限范围。应检查预览；分页、特殊懒加载、付费预览等站点可能需要额外适配。
- 单篇最多 100 张图片、每次 HTML 或图片下载最多 10 MiB，单次网络请求有超时限制。图片失败时不会标记整篇剪贴成功。
- 图片以外的嵌入视频、附件等不做本地资源归档。
- 第一版使用设置中的默认目标；标签、单次另选目标、更新覆盖旧笔记及自动批量剪贴尚未实现。
- 本轮已完成源码与生产构建验证；此记录不代表已安装版本，尚未替换 `/Applications/FoLocal.app`。
